# 半导体封测 MES 开发常用代码


## 技术栈
- 后端：C# / .NET Framework / ASP.NET
- 客户端：C# WinForm（车间现场主要使用）
- 数据库：Oracle
- 业务：工单管理、SN过站、产品追溯、质量不良、BPM审批、APQP/DRS/BRB

## 主要功能
1. 工单查询、状态维护、批量数据处理
2. 产品SN过站记录、全链路生产追溯
3. 质量不良统计、产线数据分析报表
4. 现场常见问题数据修复SQL、存储过程
5. WinForm通用数据库操作、Excel导出工具
6. ASP.NET后台管理页面基础逻辑
